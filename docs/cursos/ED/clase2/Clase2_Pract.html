BA2 – Estadística descriptiva + muestreo y sesgo

Author

Alexander Buritica

Published

February 4, 2026

Objetivo de la hora

En esta práctica guiada vamos a conectar la teoría con R:

  1. Estadística descriptiva (media, mediana, moda, varianza, desviación estándar, CV, percentiles).

  2. Población vs. muestra (simulación).

  3. Muestreo probabilístico vs. no probabilístico (sesgo).

  4. “Muestras distintas → estadísticos distintos” (variabilidad muestral).

Parte A — Descriptiva con un dataset pequeño (15–20 min)

1) Un dataset simple (horas de deporte/semana)

Usaremos un conjunto pequeño para poder calcular e interpretar fácilmente.

x <- c(2, 3, 4, 4, 5, 6, 6, 6, 7, 8, 10, 12)
x
 [1]  2  3  4  4  5  6  6  6  7  8 10 12
length(x)
[1] 12

2) Media y mediana

mean(x)
[1] 6.083333
median(x)
[1] 6

3) Moda (función casera)

R no trae una función “moda” por defecto; la construimos:

mode_stat <- function(v) {
  tab <- table(v)
  maxf <- max(tab)
  modes <- as.numeric(names(tab)[tab == maxf])
  if (maxf == 1) return(NA_real_)  # no hay moda única
  modes
}

mode_stat(x)
[1] 6
table(x)
x
 2  3  4  5  6  7  8 10 12 
 1  1  2  1  3  1  1  1  1

Interpretación guiada:

  • La moda es el valor más frecuente.

  • Puede no existir o pueden existir varias

4) Visualización rápida

hist(x, breaks = seq(0, 13, by = 1), main = "Horas de deporte (muestra)", xlab = "Horas", ylab = "Frecuencia")

5) Outliers: por qué media y mediana cuentan historias distintas

Cambiamos el último valor (12) por un extremo (30).

x_out <- c(2, 3, 4, 4, 5, 6, 6, 6, 7, 8, 10, 30)

c(
  mean_original = mean(x),
  median_original = median(x),
  mean_outlier = mean(x_out),
  median_outlier = median(x_out)
)
  mean_original median_original    mean_outlier  median_outlier 
       6.083333        6.000000        7.583333        6.000000

Parte B — Variabilidad: varianza, desviación estándar y CV (15 min)

6) Varianza y desviación estándar

var(x)   # varianza muestral (divide por n-1)
[1] 8.265152
sd(x)    # desviación estándar (raíz de la varianza)
[1] 2.874918

Interpretación :

  • La varianza es una medida de dispersión pero queda en unidades al cuadrado (horas²).

  • La desviación estándar vuelve a “horas”, así que se interpreta mejor:
    “típicamente los datos se alejan unas ~sd horas del promedio”.

7) Coeficiente de variación (CV)

cv <- sd(x) / mean(x)
cv
[1] 0.4725892

8) Ejemplo BA: comparar variabilidad relativa (Fútbol vs Yoga)

futbol <- c(5, 6, 7, 7, 8, 9)
yoga   <- c(1, 2, 2, 4, 6, 6)

data.frame(
  grupo = c("Fútbol", "Yoga"),
  media = c(mean(futbol), mean(yoga)),
  sd    = c(sd(futbol), sd(yoga)),
  cv    = c(sd(futbol)/mean(futbol), sd(yoga)/mean(yoga))
)
   grupo media       sd        cv
1 Fútbol   7.0 1.414214 0.2020305
2   Yoga   3.5 2.167948 0.6194138

Lectura:

  • Aunque las desviaciones sean parecidas, el grupo con media pequeña suele tener CV más alto.

Parte C — Percentiles

9) Percentiles con quantile()

quantile(x, probs = c(.25, .5, .75, .9))
 25%  50%  75%  90% 
4.00 6.00 7.25 9.80

Interpretación guiada:

  • P50 = mediana.

  • P90: “el 90% de los estudiantes dedica hasta (ese valor) horas o menos”.

    Parte D — Población vs muestra (simulación)

    En la vida real, la población completa suele ser inobservable. Aquí la simulamos para “ver” lo que normalmente no vemos.

    10) Crear una “población” (ingreso mensual) sesgada a la derecha

N <- 100000
poblacion <- data.frame(
  id = 1:N,
  ingreso = rlnorm(N, meanlog = 8.5, sdlog = 0.5)
)

# Parámetros poblacionales (en la vida real: desconocidos)
mu_pop  <- mean(poblacion$ingreso)
sd_pop  <- sd(poblacion$ingreso)
p90_pop <- quantile(poblacion$ingreso, .9)

c(mu_pop = mu_pop, sd_pop = sd_pop, p90_pop = p90_pop)
     mu_pop      sd_pop p90_pop.90% 
   5570.928    2962.890    9328.513

11) Tomar una muestra aleatoria simple (muestreo probabilístico)

n <- 400
muestra_srs <- poblacion[sample(1:N, n), ]

c(
  mean_srs = mean(muestra_srs$ingreso),
  sd_srs   = sd(muestra_srs$ingreso),
  p90_srs  = quantile(muestra_srs$ingreso, .9)
)
   mean_srs      sd_srs p90_srs.90% 
   5563.918    2856.608    8690.713

Mensaje clave:

  • Usamos estadísticas muestrales para aproximar parámetros poblacionales.

    Parte E — Sesgo: muestreo no probabilístico

    12) Muestra sesgada: “solo responde el top 30%” (sesgo de selección)

    Simulamos una encuesta donde solo aparecen personas con ingresos altos (por ejemplo, “usuarios premium” o “clientes activos”).

umbral <- quantile(poblacion$ingreso, 0.70)
umbral
     70% 
6399.689 
poblacion_alta <- subset(poblacion, ingreso >= umbral)

muestra_sesgada <- poblacion_alta[sample(1:nrow(poblacion_alta), n), ]

c(
  mean_pop     = mu_pop,
  mean_srs     = mean(muestra_srs$ingreso),
  mean_sesgada = mean(muestra_sesgada$ingreso)
)
    mean_pop     mean_srs mean_sesgada 
    5570.928     5563.918     8932.773

Mensaje clave (BA):

  • Una muestra sesgada puede generar conclusiones “precisas” pero equivocadas.

  • Aumentar n no corrige el sesgo si el mecanismo de selección está mal.
